# Devmax for Claude and Codex

Makes Claude and Codex better at Roblox. Devmax teaches your AI how professional Roblox developers build (secure remotes, safe DataStores, clean structure, good UI) and can make thumbnails, icons and game UIs in your chat with your Devmax credits.

No download. It is a plugin plus a link to the Devmax connector.

## Claude

1. Open Claude, then **Settings → Plugins → Add → Add marketplace**.
2. Paste `FelixPhantt/devmax-ai` and press **Sync**.
3. Install **Devmax**, then press **Connect** and **Allow**.

Claude Code (terminal):

```
/plugin marketplace add FelixPhantt/devmax-ai
/plugin install devmax@devmax
```

## Codex

1. Open Codex, then **Plugins → Add → Add marketplace**.
2. Source: `FelixPhantt/devmax-ai`. Press **Add marketplace**.
3. Install **Devmax**, then press **Connect** and **Allow**.

Learn more at https://www.devmax.dev/plugin

## Privacy

Devmax only receives what you ask it to make (your prompt) and your Devmax account. Privacy policy: https://www.devmax.dev/privacy
