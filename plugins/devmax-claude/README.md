# Devmax for Claude

Devmax gives Claude Roblox developer skills. It asks once before it helps, so it never gets in the way of normal coding.

## What it does

- **Roblox rules and checks.** Secure remotes, safe DataStores, clean game structure, modern Luau, exploit and lag reviews, debugging and UI that scales on every device.
- **Thumbnails and icons.** Roblox thumbnails, game icons and transparent UI icons, shown in your chat. Uses your Devmax credits.
- **Icon library.** Search real, professional game icons.
- **Game passes and developer products.** Devmax prepares them, you press Create on a Devmax page, and you get the ids for your scripts.

## What it connects to

The plugin contains only instructions (skills) and one connector: the Devmax server at https://api.devmax.dev/mcp. Nothing runs on your computer. Devmax receives only what you ask it to make and your Devmax account. Game pass access is optional, asks for your permission on Roblox, and can be removed at any time.

## Use it

Install the plugin, press **Connect**, then **Allow** on the Devmax page. Then ask for example:

- Add a shop with gamepasses to my Roblox game
- Check my game for exploits
- Make me a thumbnail for my game
